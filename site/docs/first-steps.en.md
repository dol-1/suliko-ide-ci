# First steps (after approved installation)

1. Launch the official BB desktop application locally on your computer; confirm it is the expected **0.49.0**.
2. Confirm the server is accessible **only on loopback**. Never expose an unauthenticated BB API to the public Internet.
3. Use a disposable or public example project; do not paste credentials. Test the projects UI and open a new thread without connecting a sensitive provider.
4. The **Suliko Hello** panel has passed isolated CI checks on actual official installed Windows and Linux GUI clients, while **Remote** remains a read-only demo/mock, not a live authenticated backend. Neither panel is installed by this guide; full marketplace/one-command setup remains unapproved.
5. If something fails, describe the generic symptom without screenshots containing personal data or account identifiers. See [troubleshooting](troubleshooting.en.md).

For future pilot participation use the [interest form](pilot.en.md). No download of a Suliko beta is currently offered.
