# Windows NotSigned — უსაფრთხო გადამოწმება და პლატფორმის საზღვრები

**მხოლოდ წინასწარი საინფორმაციო გზამკვლევი — Suliko-ს ინსტალატორი არ გამოქვეყნებულა და მისი გამოყენება პირად ან საწარმოო კომპიუტერზე არ არის დამტკიცებული.** წყარო: [BB-ის ოფიციალური desktop-v0.49.0 გამოცემა](https://github.com/get-bb/bb/releases/tag/desktop-v0.49.0) და [ინსტალაციის სტატუსი](install.ka.md). ეს ტექსტი არ არის დაყენების მოწვევა.

## SHA-256 ამოწმებს ფაილის მთლიანობას, არა გამომცემლის ხელმოწერას

ოფიციალური Windows პაკეტი კვლავ **NotSigned** არის. უკვე ნებადართულად მოპოვებული ფაილის SHA-256 შეიძლება შედარდეს **ოფიციალურ გამოცემაში დამოუკიდებლად გამოქვეყნებულ ზუსტ ჰეშთან**; მოსალოდნელი მნიშვნელობა არასოდეს უნდა გამოვიცნოთ. ქვემოთ მოცემული ბრძანება ფაილს მხოლოდ კითხულობს. ბილიკი **მაგალითია**, არც ჩამოტვირთვაა, არც გაშვება და არც ინსტალაცია.

```powershell
$ApprovedFile = 'C:\reviewed\bb-installer.exe' # მხოლოდ მაგალითის ბილიკი
Get-FileHash -LiteralPath $ApprovedFile -Algorithm SHA256
```

თუ ოფიციალური მოსალოდნელი SHA-256 უცნობია ან მიღებული შედეგი არ ემთხვევა მას, **შეჩერდით** და ფაილი არ გაუშვათ. ემთხვევის შემთხვევაშიც SHA-256 **არ ადასტურებს** გამომცემლის Authenticode ციფრულ ხელმოწერას.

## SmartScreen და NotSigned

Windows SmartScreen-ს შეუძლია გაურკვეველ გამომცემელზე გაფრთხილება აჩვენოს. **არ გამორთოთ SmartScreen, არ შეცვალოთ სისტემის დაცვა და არ აუაროთ გვერდი უსაფრთხოების გაფრთხილებას.** შეაჩერეთ პროცესი და გადაამოწმეთ ოფიციალური დოკუმენტაცია ან ჰკითხეთ უფლებამოსილ ადმინისტრატორს. CI-ის სინთეტიკური ტესტი მომხმარებლის ინსტალაციას არ ამტკიცებს.
