# Windows-ის ნდობისა და SHA-256-ის გზამკვლევი — მხოლოდ დოკუმენტაცია

**Suliko IDE-ის საჯარო ბეტა ჯერ არ გამოქვეყნებულა.** ეს გვერდი მხოლოდ ნდობის შემოწმებას ხსნის; არ არის პროგრამის დაყენების მოწვევა ან ხელმოუწერელი ფაილის გაშვების ნებართვა. წყარო: [BB 0.49.0-ის ოფიციალური გამოცემა](https://github.com/get-bb/bb/releases/tag/desktop-v0.49.0) და [იზოლირებული CI მტკიცებულება](https://github.com/dol-1/suliko-ide-ci/actions).

## რას ნიშნავს NotSigned და SmartScreen

Windows-ის ოფიციალური BB 0.49.0 NSIS ფაილი იზოლირებულ CI შემოწმებაში Authenticode-ის მიხედვით იყო **NotSigned**. ამიტომ Windows-ის **SmartScreen**-მა შესაძლოა უცნობი გამომცემლის გაფრთხილება აჩვენოს. ზუსტი **SHA-256** ჰეშის დამთხვევა მხოლოდ იმას ამოწმებს, რომ ბაიტები წინასწარ გადამოწმებულ კონკრეტულ ფაილს ემთხვევა. ეს **არ არის** გამომცემლის ციფრული ხელმოწერა და არც უსაფრთხოების ან საჯარო გამოშვების გარანტია. უსაფრთხოების კონტროლი არ გამორთოთ და გაფრთხილება არ აირიდოთ ექსპერიმენტული პროგრამის გასაშვებად.

## მხოლოდ წაკითხვითი ჰეშის შემოწმება — გაშვების გარეშე

თუ ფაილი **უკვე მიღებულია სანდო წყაროდან**, PowerShell-ით შეგიძლიათ მისი SHA-256 ნახოთ ისე, რომ პროგრამა არ გაეშვას:

```powershell
$File = '<path-to-already-downloaded-file>'
Get-FileHash -LiteralPath $File -Algorithm SHA256
```

შედეგის სრული 64-ნიშნა ჰეში შეადარეთ ზუსტად **იმავე ვერსიისა და ფაილის** დამოუკიდებლად გადამოწმებულ ოფიციალურ ჰეშს. თუ ჰეში განსხვავდება, სანდო საკონტროლო მნიშვნელობა არ გაქვთ, წყარო გაურკვეველია ან Windows გაფრთხილებას აჩვენებს — **შეწყვიტეთ**. Suliko Hello პლაგინის არქივის ჰეში Windows ინსტალერის ჰეშის შემცვლელი არ არის.

## Windows-ის GUI და CLI ერთმანეთისგან განსხვავდება

Windows-ის native **GUI** არ ნიშნავს BB-ის native PowerShell CLI-ს. BB 0.49.0-ის შემთხვევაში Windows-ზე **CLI გამოიყენება Ubuntu WSL2-ით** და Linux-ის ფაილური ბილიკებით; native PowerShell-ის `bb project create` მხარდაჭერა დაპირებული არ არის. ჩვენ მხოლოდ უფასო, დროებით CI კომპიუტერებზე შევამოწმეთ ფუნქციები. საჯარო დოკუმენტაციაში Remote არის სინთეტიკური/mock დემო და არა რეალური ავტორიზებული სერვისი.
