# ინსტალაცია — მიმდინარე მდგომარეობა

**Suliko-ს სრული ერთბრძანებიანი ინსტალატორი ჯერ არ გამოქვეყნებულა.** ექსპერიმენტული სკრიპტები რეალურ სამუშაო გარემოში არ გამოიყენოთ.

1. BB-ის ოფიციალური ვერსია 0.49.0 ნახეთ [გამოშვების გვერდზე](https://github.com/get-bb/bb/releases/tag/desktop-v0.49.0). macOS arm64 მხარდაჭერილია; Windows x64-ისა და Linux x86_64-ის Desktop პაკეტები ჯერ **ალფა** ეტაპზეა. Windows-ზე საჭიროა Git for Windows. [ოფიციალური ინსტრუქცია](https://github.com/get-bb/bb/blob/desktop-v0.49.0/README.md).
2. Suliko-ს [საწყისი გადამოწმების სკრიპტები](https://github.com/dol-1/suliko-ide-ci/tree/main/scripts) ჯერ მხოლოდ **preview**-ა: `suliko-setup.sh --dry-run` ან `suliko-setup.ps1 -DryRun`. ჰეშის შემოწმება ავტომატურ ინსტალაციას **არ ნიშნავს**.
3. უსაფრთხო კონფიგურაციის, marketplace-ისა და პლაგინების სრული ინსტალაცია ტესტირებას ელოდება. მანამდე საჯარო ქსელში BB არ გამოიტანოთ.

## Windows: CLI მხოლოდ WSL2-ით, GUI — native (D-174)

BB 0.49.0-ის [ოფიციალური bb-app დოკუმენტაციით](https://github.com/get-bb/bb/blob/desktop-v0.49.0/packages/bb-app/README.md), **CLI Windows-ზე მხარდაჭერილია Ubuntu WSL2-ში**, Linux-ის ბილიკებით. Native PowerShell-ის `bb project create` არ არის მხარდაჭერილი გარანტია. **ოფიციალური Windows GUI მუშაობს native რეჟიმში** და იზოლირებულ საჯარო CI-ში რეალურ დაყენებულ `bb.exe`-ში Suliko Hello პანელი გამოჩნდა. D-174-ის ერთბრძანებიანი GUI/SEC-02/loopback/უსაფრთხო წაშლა **მხოლოდ იზოლირებულ საჯარო CI-ში უკვე შემოწმებულია სამივე OS-ზე**: [source 43743127349](https://github.com/dol-1/suliko-ide-ci/actions/runs/43743127349) და [main 43743593613](https://github.com/dol-1/suliko-ide-ci/actions/runs/43743593613) წარმატებულია. ეს **არ ნიშნავს საჯარო ინსტალატორის გამოცემას ან დამოუკიდებელ უსაფრთხოების დამტკიცებას**.

Windows-ის ოფიციალური ინსტალერი ისევ **NotSigned**-ია: SHA-256 არ არის გამომცემლის ხელმოწერა. არც RC ტეგი, არც Beta, არც დამოუკიდებელი SEC-04 sign-off არ გამოცემულა. პირად ან საწარმოო კომპიუტერზე საცდელი სკრიპტები არ გაუშვათ.

[პირველი ნაბიჯები](first-steps.ka.md) · [პრობლემების მოგვარება](troubleshooting.ka.md)

**Windows-ის ნდობის გაფრთხილება (BB 0.49.0):** ოფიციალური Windows x64 ფაილის SHA-256 ემთხვევა გამოცემის ოფიციალურ ჰეშს, თუმცა Windows CI-ში Authenticode-ის შედეგია **NotSigned**. upstream-ის დოკუმენტაციით, ხელმოწერის სერტიფიკატის გარეშე პაკეტი ხელმოუწერელია და შესაძლოა SmartScreen-ის გაფრთხილება გამოიწვიოს. SHA-256 არ ადასტურებს გამომცემლის ციფრულ ხელმოწერას. Claude-ის D-090-ის გადაწყვეტილებით, მხოლოდ ერთჯერად **იზოლირებულ, უპრივილეგიო Windows CI ტესტში** დაშვებულია ზუსტად ეს SHA-256-ით დამოწმებული `NotSigned` ფაილი; ეს გამომცემლის ხელმოწერის შემცვლელი **არ არის**. [GitHub 43550483976](https://github.com/dol-1/suliko-ide-ci/actions/runs/43550483976) დასრულდა წარმატებით: NSIS-ის მომხმარებლის ინსტალაცია, 15-წამიანი აპის მუშაობა და წაშლა. [შემდგომი Windows-2022 CI ტესტი 43563716016](https://github.com/dol-1/suliko-ide-ci/actions/runs/43563716016) ადასტურებს, რომ **ოფიციალურად დაყენებულ რეალურ `bb.exe` აპში Suliko Hello პანელი გამოჩნდა**. იმავე ტესტში, მაგრამ **ცალკე, იმავე BB-ის წყაროდან აწყობილ CLI-ზე**, გადამოწმდა loopback SEC-02 და Hello-ს ჩართვა; ეს სრული ინსტალაციის დამტკიცება არ არის. [უფასო Windows-2025 CI ტესტმა 43569975316](https://github.com/dol-1/suliko-ide-ci/actions/runs/43569975316) შემდგომ დაადასტურა იგივე **რეალურად დაყენებულ `bb.exe`-ში Hello პანელი**, იმავე ტესტში **ცალკე stock CLI-ზე SEC-02/Hello**, და მომხმარებლის სივრცეში უსაფრთხო წაშლა 900 წამზე ნაკლებ დროში. BB-ის უცვლელი წყარო დროებითი CI toolchain-ით აიგო; ოფიციალური Windows ფაილი კვლავ **NotSigned**-ია. Windows-ისა და დანარჩენი 2 OS-ის ერთბრძანებიანი ინსტალაციის ინტეგრაცია **დადასტურებულია მხოლოდ სინთეტიკურ CI გარემოში** (D-174, exact postmain [43743593613](https://github.com/dol-1/suliko-ide-ci/actions/runs/43743593613)). მომხმარებლისთვის საჯარო ინსტალატორი **არ გამოცემულა**: Windows-ის გამომცემლის ხელმოწერა კვლავ არ არსებობს, უცვლელი marketplace RC ტეგი არ დამტკიცებულა და დამოუკიდებელი SEC-04 განხილვა არ დასრულებულა. SmartScreen-ის გვერდის ავლას არ გირჩევთ. იხილეთ [upstream-ის Windows ინსტრუქცია](https://github.com/get-bb/bb/blob/desktop-v0.49.0/apps/desktop/README.md).

### D141 — ერთბრძანებიანი საცდელი დაყენება მხოლოდ CI-სთვის

საწყისი ჩამოტვირთვის/შემოწმების გარდა, Linux/macOS-ის `--install` და `--uninstall`, Windows-ის აშკარა ხელმოუწერელი ინსტალაციის თანხმობის `-Install -AllowUnsignedVerified` და `-Uninstall` რეჟიმები არსებობს, მაგრამ **მომხმარებლებისთვის არ გამოქვეყნებულა**. სუფთა იზოლირებულ CI-ში წარმატებით შემოწმდა [Windows-2025 43610379841](https://github.com/dol-1/suliko-ide-ci/actions/runs/43610379841) ოფიციალური SHA-256-ით დამოწმებული **NotSigned** NSIS, [Linux 43611754307](https://github.com/dol-1/suliko-ide-ci/actions/runs/43611754307) AppImage-ის მომხმარებლის დაყენება და [macOS 43612704684](https://github.com/dol-1/suliko-ide-ci/actions/runs/43612704684) ხელმოწერილი DMG-ის დაყენება, quarantine-ის შენარჩუნება, სავალდებულო `codesign` და Gatekeeper `spctl`. ცალკეულ ტესტებში რეალური GUI Hello პანელი ჩანდა და საკუთარი ფაილები 900 წამამდე წაიშალა.

**D-141-ის ისტორიული ნაწილობრივი ფარგლები გაფართოვდა მხოლოდ CI-ში:** D-174-ის [მთავარ ბრენჩზე სინთეტიკური ტესტი](https://github.com/dol-1/suliko-ide-ci/actions/runs/43743593613) ახლა ერთი მომხმარებლის ბრძანებით ამოწმებს ოფიციალურად დაყენებულ BB GUI-ს, იმავე საკუთრებაში მყოფ CLI-ს, Hello პანელს, SEC-02-სა და დაცული მომხმარებლის მონაცემების ხელუხლებელ წაშლას Linux/macOS/Windows-ზე. უცვლელი RC marketplace ტეგი, Windows-ის გამომცემლის ხელმოწერა, დამოუკიდებელი SEC-04 აუდიტი, საჯარო რელიზი და ბეტა **არ არის მიღებული**. ექსპერიმენტული დაყენება პირად ან საწარმოო კომპიუტერზე არ გაუშვათ.

დიაგნოსტიკური ტესტის GREEN **არ ნიშნავს** ინსტალაციის დამტკიცებას. Beta-ს ყველა კრიტერიუმი შესრულებული არ არის. Suliko-ს დაუსრულებელი სკრიპტები სამუშაო კომპიუტერზე არ გაუშვათ.

პროდუქტის გასაღებები მხოლოდ BB-ის ოფიციალურ პარამეტრებში შეიყვანეთ და არასოდეს გააზიაროთ საჯარო issue-ში. იხილეთ [დახმარება](troubleshooting.ka.md) და [ხშირი კითხვები](faq.ka.md).
