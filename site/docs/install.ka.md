# ინსტალაცია — მიმდინარე მდგომარეობა

**Suliko-ს სრული ერთბრძანებიანი ინსტალატორი ჯერ არ გამოქვეყნებულა.** ექსპერიმენტული სკრიპტები რეალურ სამუშაო გარემოში არ გამოიყენოთ.

1. BB-ის ოფიციალური ვერსია 0.49.0 ნახეთ [გამოშვების გვერდზე](https://github.com/get-bb/bb/releases/tag/desktop-v0.49.0). macOS arm64 მხარდაჭერილია; Windows x64-ისა და Linux x86_64-ის Desktop პაკეტები ჯერ **ალფა** ეტაპზეა. Windows-ზე საჭიროა Git for Windows. [ოფიციალური ინსტრუქცია](https://github.com/get-bb/bb/blob/desktop-v0.49.0/README.md).
2. Suliko-ს [საწყისი გადამოწმების სკრიპტები](https://github.com/dol-1/suliko-ide-ci/tree/main/scripts) ჯერ მხოლოდ **preview**-ა: `suliko-setup.sh --dry-run` ან `suliko-setup.ps1 -DryRun`. ჰეშის შემოწმება ავტომატურ ინსტალაციას **არ ნიშნავს**.
3. უსაფრთხო კონფიგურაციის, marketplace-ისა და პლაგინების სრული ინსტალაცია ტესტირებას ელოდება. მანამდე საჯარო ქსელში BB არ გამოიტანოთ.

[პირველი ნაბიჯები](first-steps.ka.md) · [პრობლემების მოგვარება](troubleshooting.ka.md)

**Windows-ის ნდობის გაფრთხილება (BB 0.49.0):** ოფიციალური Windows x64 ფაილის SHA-256 ემთხვევა გამოცემის ოფიციალურ ჰეშს, თუმცა Windows CI-ში Authenticode-ის შედეგია **NotSigned**. upstream-ის დოკუმენტაციით, ხელმოწერის სერტიფიკატის გარეშე პაკეტი ხელმოუწერელია და შესაძლოა SmartScreen-ის გაფრთხილება გამოიწვიოს. SHA-256 არ ადასტურებს გამომცემლის ციფრულ ხელმოწერას. ჩვენი ინსტალაციის უსაფრთხოების შემოწმება ასეთ ფაილს **არ უშვებს**; Windows-ზე ავტომატური ინსტალაცია დამტკიცებული **არ არის**. SmartScreen-ის გვერდის ავლას არ გირჩევთ. იხილეთ [upstream-ის Windows ინსტრუქცია](https://github.com/get-bb/bb/blob/desktop-v0.49.0/apps/desktop/README.md).

## სამივე პლატფორმის ტესტირების რეალური მდგომარეობა

ქვემოთ მოცემულია მხოლოდ **GitHub-ის იზოლირებულ ტესტურ გარემოში** ნანახი შედეგები — ეს ჯერ არ არის მომხმარებლისთვის გამოსაყენებელი ინსტალატორი.

| პლატფორმა | რა გადამოწმდა | რა აკლია |
| --- | --- | --- |
| Linux x86_64 | ოფიციალური AppImage-ის SHA-256, უპრივილეგიო გაშვება და საკუთარი ფაილების წაშლა. ცალკე, BB-ის სატესტო სერვერზე — უსაფრთხო პროფილი და ლოკალური Hello | ერთი დასრულებული ბრძანება, marketplace-ის RC tag, სრული წაშლა და პაკეტში პლაგინის მუშაობა |
| macOS Apple Silicon | ოფიციალური DMG-ის SHA-256, ხელმოწერა, მომხმარებლის აპის გაშვება და წაშლა. **იმავე CI ტესტში ცალკე, იმავე BB წყაროდან აწყობილ CLI-ზე** გაიარა loopback SEC-02 და ჩაირთო ლოკალური Hello ([ტესტის მტკიცებულება](https://github.com/dol-1/suliko-ide-ci/actions/runs/43494714262)); **ეს არ ამტკიცებს პლაგინის მუშაობას ხელმოწერილ აპში** | ერთი სრული ინსტალაციის ბრძანება, marketplace-ის RC ტეგით დაყენება უშუალოდ პაკეტში და სრული წაშლა |
| Windows x64 | ოფიციალური EXE-ის SHA-256 სწორია, მაგრამ Authenticode არის **NotSigned** | ხელმოწერის ნდობის დამოუკიდებელი გადაწყვეტილება და უსაფრთხო ინსტალაციის ტესტი; ტესტმა EXE არ გაუშვა |

დიაგნოსტიკური ტესტის GREEN **არ ნიშნავს** ინსტალაციის დამტკიცებას. Beta-ს ყველა კრიტერიუმი შესრულებული არ არის. Suliko-ს დაუსრულებელი სკრიპტები სამუშაო კომპიუტერზე არ გაუშვათ.

პროდუქტის გასაღებები მხოლოდ BB-ის ოფიციალურ პარამეტრებში შეიყვანეთ და არასოდეს გააზიაროთ საჯარო issue-ში. იხილეთ [დახმარება](troubleshooting.ka.md) და [ხშირი კითხვები](faq.ka.md).
