# ინსტალაცია — მიმდინარე მდგომარეობა

**Suliko-ს სრული ერთბრძანებიანი ინსტალატორი ჯერ არ გამოქვეყნებულა.** ექსპერიმენტული სკრიპტები რეალურ სამუშაო გარემოში არ გამოიყენოთ.

1. BB-ის ოფიციალური ვერსია 0.49.0 ნახეთ [გამოშვების გვერდზე](https://github.com/get-bb/bb/releases/tag/desktop-v0.49.0). macOS arm64 მხარდაჭერილია; Windows x64-ისა და Linux x86_64-ის Desktop პაკეტები ჯერ **ალფა** ეტაპზეა. Windows-ზე საჭიროა Git for Windows. [ოფიციალური ინსტრუქცია](https://github.com/get-bb/bb/blob/desktop-v0.49.0/README.md).
2. Suliko-ს [საწყისი გადამოწმების სკრიპტები](https://github.com/dol-1/suliko-ide-ci/tree/main/scripts) ჯერ მხოლოდ **preview**-ა: `suliko-setup.sh --dry-run` ან `suliko-setup.ps1 -DryRun`. ჰეშის შემოწმება ავტომატურ ინსტალაციას **არ ნიშნავს**.
3. უსაფრთხო კონფიგურაციის, marketplace-ისა და პლაგინების სრული ინსტალაცია ტესტირებას ელოდება. მანამდე საჯარო ქსელში BB არ გამოიტანოთ.

[პირველი ნაბიჯები](first-steps.ka.md) · [პრობლემების მოგვარება](troubleshooting.ka.md)

**Windows-ის ნდობის გაფრთხილება (BB 0.49.0):** ოფიციალური Windows x64 ფაილის SHA-256 ემთხვევა გამოცემის ოფიციალურ ჰეშს, თუმცა Windows CI-ში Authenticode-ის შედეგია **NotSigned**. upstream-ის დოკუმენტაციით, ხელმოწერის სერტიფიკატის გარეშე პაკეტი ხელმოუწერელია და შესაძლოა SmartScreen-ის გაფრთხილება გამოიწვიოს. SHA-256 არ ადასტურებს გამომცემლის ციფრულ ხელმოწერას. Claude-ის D-090-ის გადაწყვეტილებით, მხოლოდ ერთჯერად **იზოლირებულ, უპრივილეგიო Windows CI ტესტში** დაშვებულია ზუსტად ეს SHA-256-ით დამოწმებული `NotSigned` ფაილი; ეს გამომცემლის ხელმოწერის შემცვლელი **არ არის**. [GitHub 43550483976](https://github.com/dol-1/suliko-ide-ci/actions/runs/43550483976) დასრულდა წარმატებით: NSIS-ის მომხმარებლის ინსტალაცია, 15-წამიანი აპის მუშაობა და წაშლა. [შემდგომი Windows-2022 CI ტესტი 43563716016](https://github.com/dol-1/suliko-ide-ci/actions/runs/43563716016) ადასტურებს, რომ **ოფიციალურად დაყენებულ რეალურ `bb.exe` აპში Suliko Hello პანელი გამოჩნდა**. იმავე ტესტში, მაგრამ **ცალკე, იმავე BB-ის წყაროდან აწყობილ CLI-ზე**, გადამოწმდა loopback SEC-02 და Hello-ს ჩართვა; ეს სრული ინსტალაციის დამტკიცება არ არის. [უფასო Windows-2025 CI ტესტმა 43569975316](https://github.com/dol-1/suliko-ide-ci/actions/runs/43569975316) შემდგომ დაადასტურა იგივე **რეალურად დაყენებულ `bb.exe`-ში Hello პანელი**, იმავე ტესტში **ცალკე stock CLI-ზე SEC-02/Hello**, და მომხმარებლის სივრცეში უსაფრთხო წაშლა 900 წამზე ნაკლებ დროში. BB-ის უცვლელი წყარო დროებითი CI toolchain-ით აიგო; ოფიციალური Windows ფაილი კვლავ **NotSigned**-ია. მომხმარებლისთვის Windows-ის ავტომატური სრული ინსტალაცია **ჯერ არ არის დამტკიცებული** — გამომცემლის ხელმოწერა, უცვლელი RC marketplace ტეგი და სამივე OS-ზე ერთი ბრძანებით სრული ინსტალაცია კვლავ დასამტკიცებელია. SmartScreen-ის გვერდის ავლას არ გირჩევთ. იხილეთ [upstream-ის Windows ინსტრუქცია](https://github.com/get-bb/bb/blob/desktop-v0.49.0/apps/desktop/README.md).

პროდუქტის გასაღებები მხოლოდ BB-ის ოფიციალურ პარამეტრებში შეიყვანეთ და არასოდეს გააზიაროთ საჯარო issue-ში. იხილეთ [დახმარება](troubleshooting.ka.md) და [ხშირი კითხვები](faq.ka.md).
