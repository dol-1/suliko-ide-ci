# კონფიდენციალურობა და უსაფრთხოება

პილოტის მსურველებისგან **არ ვითხოვთ** სახელს, ასაკს, ელფოსტას, ტელეფონს, სამუშაო ადგილის მონაცემებს, პირად რეპოზიტორიებს, მოწყობილობის ID-ს, API გასაღებებს ან screenshot-ებს. [GitHub-ის ფორმა](pilot.ka.md) **საჯაროა**: შეტყობინებები სხვებსაც უჩანს. issue-ის დახურვა უკვე გამოქვეყნებულ ტექსტს არ შლის.

საჯარო დოკუმენტაციის CI აწყობს სტატიკურ გვერდებს; საკუთარი მომხმარებლის ტელემეტრია არ დაუმატებია. GitHub-ის ვებ-სერვისს საკუთარი პოლიტიკა აქვს.

Suliko-ს საჯარო ბეტა და production backend ჯერ არ გამოქვეყნებულა. BB-ის ცალკე ტელემეტრია მისივე კონფიგურაციით იმართება; `BB_TELEMETRY=false` ლოკალურადაც უნდა დადასტურდეს.
