# Suliko Remote — მხოლოდ სტატუსის პანელი

პანელში ჩანს **მოწყობილობის მდგომარეობა**, **მოლოდინში მყოფი თანხმობები** და **შედეგები**. დამტკიცება ხდება **მხოლოდ Remote-ის ცალკე დაცულ გვერდზე** და არა IDE-ში. უცნობი შედეგი წარმატებად არ ითვლება.

მიმდინარე CI ტესტავს მხოლოდ სინთეტიკურ და mock კლიენტურ კონტრაქტებს; რეალურ Remote-ს არ უკავშირდება და ტოკენს არ იღებს. მონაცემები საჯარო issue-ში არ ჩაწეროთ.
