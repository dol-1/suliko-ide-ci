# Suliko Remote — მხოლოდ სტატუსის პანელი

სამომავლო პლაგინი აჩვენებს **მოწყობილობის მდგომარეობას, მოლოდინში მყოფ დამტკიცებებსა და შედეგებს**. დამტკიცება ხდება **მხოლოდ Remote-ის ცალკე დაცულ გვერდზე** და არა IDE-ში. უცნობი შედეგი წარმატებად არ ითვლება.

მიმდინარე CI ტესტავს მხოლოდ სინთეტიკურ და mock კლიენტურ კონტრაქტებს; რეალურ Remote-ს არ უკავშირდება და token-ს არ იღებს. მონაცემები საჯარო issue-ში არ ჩაწეროთ.
