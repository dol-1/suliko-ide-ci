# Suliko IDE — user help

Welcome to the **pre-release documentation preview**. Suliko IDE is an optional add-on experience built around the **official BB application**, with Suliko-owned plugins and local-only configuration. Suliko does not redistribute, modify or replace BB core. A working public beta is **not yet available**.

Start with [installation status](install.en.md), then [first steps](first-steps.en.md), [private Web access](web.en.md), or [Remote read-only status](remote.en.md). Learn what we store in [privacy](privacy.en.md) and review [troubleshooting](troubleshooting.en.md).
