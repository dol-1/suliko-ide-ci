# Privacy and security

We do **not** ask pilot applicants to provide real names, age, emails, phone numbers, workplace details, private repositories, device IDs, API keys, secrets or screenshots. The [pilot signup issue](pilot.en.md) is **public**: all written responses are visible. Closing an issue does not automatically erase previously public text.

The public documentation CI builds static Markdown; it does not run telemetry or collect visitor identity. GitHub may process normal web requests under GitHub's own policies; this page cannot audit third-party analytics.

No Suliko production backend or public beta enrollment is offered here. Stock BB's separate telemetry and data handling are governed by its own documented configuration; the proposed hardened profile sets `BB_TELEMETRY=false`, but live efficacy must be verified per install.

Remote credentials belong only to the authorized Remote service and must never be put in issues, docs or test fixtures.
