# პირადი Web წვდომა

**საჯარო მრავალმომხმარებლიანი BB Web სერვისი არ არსებობს.** BB-ის დაუცველი API საჯარო IP-ზე არ გამოიტანოთ.

სამომავლო ვარიანტია **მფლობელის კონტროლირებადი** ლოკალური BB, პირადი Tailscale-ითა და Tailscale Serve-ით — მხოლოდ წვდომის და უსაფრთხოების შემოწმების შემდეგ. დოკუმენტაციის საიტის გამოქვეყნება Tailscale-ს არ ააქტიურებს.

არ გამოიყენოთ საჯარო port-forward ან Tailscale Funnel უსაფრთხოების ტესტის ნაცვლად. Desktop/Web თანასწორობა ჯერ **დადასტურებული არ არის**.
