# macOS-ისა და Linux-ის ნდობის გზამკვლევი — SHA-256, Gatekeeper და პაკეტები

**მხოლოდ დოკუმენტაციის წინასწარი ვერსია. Suliko IDE-ის საჯარო ბეტა ჯერ არ გამოქვეყნებულა.** ეს გვერდი ინფორმაციული შემოწმებაა და არა ჩამოტვირთვის, ინსტალაციის ან საეჭვო პროგრამის გაშვების მოწვევა. BB Desktop-ის პაკეტსა და Suliko Hello პლაგინის არქივს **სხვადასხვა ფაილი და სხვადასხვა SHA-256** აქვს.

## რას ადასტურებს SHA-256 და რას — არა

SHA-256-ის სრული **64-ნიშნა თექვსმეტობითი მნიშვნელობა** მხოლოდ იმას ამოწმებს, ემთხვევა თუ არა **უკვე მიღებული ფაილის** ბაიტები ზუსტად იმავე ვერსიის, სისტემის, არქიტექტურისა და ფაილის დამოუკიდებლად გადამოწმებულ ჰეშს. ჰეშების დამთხვევა **არ ადასტურებს** გამომცემლის ვინაობას, ნოტარიზაციას, პროგრამის სრულ უსაფრთხოებას ან გამოშვების ნებართვას. თუ სანდო საკონტროლო ჰეში მიუწვდომელია, წყარო გაურკვეველია, ჰეში არ ემთხვევა ან სისტემა გაფრთხილებას აჩვენებს — **შეწყვიტეთ შემოწმება და მოითხოვეთ ოფიციალურად დამტკიცებული გამოშვება**.

## macOS: მხოლოდ წაკითხვითი შემოწმება და Gatekeeper

თუ ფაილი უკვე გაქვთ სანდო წყაროდან, Terminal-ში შეგიძლიათ SHA-256 ნახოთ ისე, რომ ფაილი **არ გაეშვას და არ დაინსტალირდეს**:

```sh
FILE='<path-to-existing-file>'
shasum -a 256 "$FILE"
```

**Gatekeeper** ამოწმებს გამომცემლის იდენტობას და შესაბამის შემთხვევაში Apple-ის **notarization**-ს. თუ macOS ვერ ამოწმებს შემქმნელს ან მავნე პროგრამის სტატუსს, გაფრთხილება არ არის უსაფრთხოების დაცვის გვერდის ავლის მიზეზი. არ გამორთოთ Gatekeeper, არ გააუქმოთ უსაფრთხოების ნიშნები და არ უგულებელყოთ სისტემური გაფრთხილება. გამოიყენეთ მხოლოდ დამტკიცებული გამოშვება, რომლის წყარო და გამომცემელი გადამოწმებულია. **ჩვენ არ ვამტკიცებთ, რომ Suliko-ს macOS პაკეტი ხელმოწერილია ან ნოტარიზებულია.**

ოფიციალური წყაროები: [Apple — უსაფრთხოდ გახსენით პროგრამები](https://support.apple.com/en-us/102445) და [Apple Developer — Developer ID](https://developer.apple.com/developer-id/).

## Linux: მხოლოდ ჰეშის წაკითხვა და პაკეტის წარმომავლობა

უკვე მიღებული Linux-ის პაკეტის ან არქივის SHA-256 შეგიძლიათ ნახოთ მისი **დაყენებისა და შესრულების გარეშე**:

```sh
FILE='<path-to-existing-file>'
sha256sum "$FILE"
```

სრული ჰეში შეადარეთ **ზუსტად იმავე ფაილის, Linux-ის გამოცემისა და არქიტექტურის** დამოუკიდებლად გადამოწმებულ მნიშვნელობას. Linux-ზე პაკეტების საცავის წარმომავლობა, გამომცემლის ხელმოწერა და პაკეტის ხელმოწერის შემოწმება SHA-256-ისგან დამოუკიდებლად მნიშვნელოვანია. ჰეშის დამთხვევა არ ნიშნავს, რომ ფაილი უნდა გაუშვათ; ნუ გაუშვებთ ქსელიდან მიღებულ კოდს პირდაპირ shell-ში.
