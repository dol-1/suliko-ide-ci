# გახდი Suliko IDE-ის პილოტი

Suliko IDE ჯერ ტესტირების ეტაპზეა. შეგიძლია დარეგისტრირდე **ორ-კვირიანი, ნებაყოფლობითი პილოტისთვის** [GitHub-ის საჯარო ფორმით](https://github.com/dol-1/suliko-ide-ci/issues/new?template=pilot-signup.yml). რეგისტრაცია არ ნიშნავს, რომ აპლიკაცია უკვე მზადაა ან ადგილი გარანტირებულია.

ფორმა მოითხოვს მხოლოდ ოპერაციულ სისტემას, Desktop/Web-ის არჩევანსა და საცდელი გამოყენების ტიპს. უკუკავშირს GitHub issue-ის კომენტარებში მივიღებთ; სურვილის შემთხვევაში შეგიძლია issue დახურო. დახურული საკითხი საჯაროდ კვლავ ჩანს.

**კონფიდენციალურობა:** Issue საჯაროა. არ მიუთითო სახელი, ასაკი, ელფოსტა, ტელეფონი, მისამართი, სამუშაოს პირადი დეტალები, ანგარიშები, token-ები ან საიდუმლოებები. არ ატვირთო პირადი screenshot-ები. გამოიყენე მხოლოდ სატესტო ან საჯარო მონაცემები.

პილოტის დროს შემოგთავაზებთ მოკლე კითხვარს დაყენების სიმარტივეზე, პირველი ამოცანის წარმატებაზე, გამოყენების სიხშირეზე, შეცდომებზე, Remote panel-ის სარგებლობაზე და გადახდის სურვილზე. პასუხები ნებაყოფლობითი იქნება. ინდივიდუალური ჩანაწერები საჯაროდ არ გადავიტანთ ანგარიშში; შედეგებს მხოლოდ განზოგადებულად შევაჯამებთ.
