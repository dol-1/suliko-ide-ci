# პრობლემების მოგვარება

- **ინსტალაცია ვერ დადასტურდა:** შეამოწმეთ OS, CPU და BB-ის ოფიციალური ვერსია. გადაუმოწმებელი ფაილი არ გაუშვათ.
- **სერვერი არ ჩანს:** შეამოწმეთ ლოკალური გაშვება და loopback. ამის გამო firewall არ გამორთოთ.
- **პლაგინის პანელი არ ჩანს:** Suliko Hello/Remote ჯერ ტესტირების ეტაპზეა; არ ჩათვალოთ, რომ უკვე დაყენებულია.
- **provider მიუწვდომელია:** გადაამოწმეთ მისი ოფიციალური კონფიგურაცია, მაგრამ API გასაღები საჯაროდ არ გააზიაროთ.
- **Remote შედეგი უცნობია:** გადაამოწმეთ დაცულ Remote გვერდზე. უცნობი შედეგი არ არის წარმატება.

[პილოტის ფორმა](pilot.ka.md) გამოიყენეთ მხოლოდ ზოგადი, არასენსიტიური აღწერისთვის. `suliko doctor` ამჟამად სინთეტიკური preview-ა.

## Doctor და მხარდაჭერის ფაილი

საჯარო `suliko-doctor` ჯერ ამოწმებს მხოლოდ **სინთეტიკურ, შეზღუდული ფორმატის** ანგარიშს და უარყოფს საცდელ token-ებს, პირად ბილიკებსა და ელფოსტის მსგავს ტექსტს. რეალური კომპიუტერის სრული დიაგნოსტიკის ინსტრუმენტი ჯერ არ არის. ნებისმიერი ლოგი უსაფრთხოდ გასაზიარებლად ავტომატურად არ მიიჩნიოთ.

პრობლემის აღწერისას მიუთითეთ მხოლოდ OS/CPU-ის ტიპი, BB-ის ვერსია, ფუნქცია და ზოგადი სიმპტომი. არ ატვირთოთ raw log, გასაღებები, კერძო რეპოზიტორიის მისამართები, დაუფარავი screenshot-ები ან Remote მოწყობილობის ID. უცნობი Remote შედეგი გადაამოწმეთ მხოლოდ უფლებამოსილ Remote გვერდზე და არ გაიმეოროთ მოქმედება შედეგის გამოსაცდელად.
