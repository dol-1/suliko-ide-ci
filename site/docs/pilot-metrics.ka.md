# პილოტის მეტრიკები და უკუკავშირის კლასიფიკაცია (სინთეტიკური შაბლონი)

**სინთეტიკური მაგალითი — არა რეალური მონაწილეები, გაზომვები, დაწყებული პილოტი ან ბეტა-მზადყოფნა.** ფარული ტელემეტრია და პირადი მონაცემების შეგროვება არ გამოიყენება. ორკვირიანი პილოტისთვის საჭიროა ნებაყოფლობითი თანხმობა და ცალკე უსაფრთხოების/პროდუქტის ნებართვა.

## კონფიდენციალური, შეზღუდული შეგროვება

- გამოიყენეთ მხოლოდ საერთო რაოდენობები და შემთხვევითი მოკლე კოდები. საჯარო ცხრილში არ გადაიტანოთ სახელი, ელფოსტა, მოწყობილობის იდენტიფიკატორი, სახლის საქაღალდე, ეკრანის სურათი, API გასაღები, პირადი კოდი, IP მისამართი ან იდენტიფიცირებადი ტექსტი.
- უკუკავშირი მხოლოდ თანხმობის შემდეგ მიიღეთ. მონაწილეს შეუძლია უარი თქვას ან შეწყვიტოს მონაწილეობა. GitHub-ის დახურული issue შეიძლება მაინც საჯარო დარჩეს.
- პერსონალური წყარო და კავშირი ინახება მხოლოდ შესაბამისი ნებართვითა და შეზღუდული წვდომით. ანგარიშში გამოიყენეთ მხოლოდ განზოგადებული კატეგორიები. კავშირის შენახვა დაიცავს დამტკიცებულ 30-დღიან წესს.
- უცნობი შედეგი აღნიშნეთ **N/A**-თი და არა ნულით. ჩამოტვირთვა, რეგისტრაცია ან CI-ის წარმატება არ ნიშნავს რეალურ ინსტალაციას.
