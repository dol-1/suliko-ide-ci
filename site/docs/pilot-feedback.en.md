# Future two-week pilot: voluntary feedback template

**NOT OPEN; no actual participants, results or hidden telemetry.** Copy only the category answers below into an approved consented pilot channel *after* a separate release/security GO. A public GitHub issue is visible even when closed: never post names, ages, email, employer, address, personal device IDs, private code, home paths, logs, screenshots, secrets, payment details or doctor bundles. All questions are optional; "prefer not to say" and withdrawal are valid.

| Optional question | Nonidentifying answer choices |
|---|---|
| Environment | Windows GUI / macOS / Linux / Web / prefer not to say |
| First-task attempt | Yes / no / prefer not to say |
| First-task outcome | Completed / did not complete / unknown / prefer not to say |
| Approximate time to first task | Under 5m / 5–15m / over 15m / unknown / prefer not to say |
| Setup outcome | Verified / blocked / not attempted / unknown |
| Doctor live check | Verified / `review-required` / not attempted; never attach raw bundle |
| Day-7 use (only if eligible and consenting) | Returned / did not return / not eligible / unknown |
| Remote mock usefulness | Useful / not useful / not tried / prefer not to say; no real approvals |
| Optional hypothetical monthly price band | None / low / medium / high / prefer not to say; NOT a purchase |
| Generic feedback code | Version mismatch / Hello absent / setup / docs / publisher-trust / other generic category |

**Reporting rule:** each metric needs a consenting numerator, a corresponding eligible denominator and a date window; unknown/zero denominators are **N/A**, never 100%. Time-to-first-task **p50/p90** require enough actual consented numeric measurements; do not turn bands into fake precision. Any Remote approval-success metric remains **N/A** without a real authorized service. Never report synthetic CI results as pilot outcomes.
