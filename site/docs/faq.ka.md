# ხშირად დასმული კითხვები

**Suliko IDE ცვლის BB-ს?** არა. Suliko იყენებს BB-ის უცვლელ საფუძველს და ამატებს საკუთარ პლაგინებს, კონფიგურაციასა და ინსტალაციის ტესტებს.

**მზა ბეტას უკვე დავაყენებ?** ჯერ არა. სამივე OS-ზე სრული დაყენება, marketplace-ის RC ტესტი, Desktop/Web parity, საჯარო დოკუმენტაციის ხელმისაწვდომობა და release gate ბოლომდე დადასტურებული არ არის.

**რატომ აჩვენებს Windows გაფრთხილებას?** BB 0.49.0-ის EXE-ის SHA-256 სწორია, მაგრამ საჯარო CI-ში Authenticode-ის სტატუსია `NotSigned`. ჰეში გამომცემლის ციფრულ ხელმოწერას არ უდრის. უსაფრთხოების გაფრთხილებას გვერდი არ აუაროთ.

**API გასაღები უნდა გამოვაქვეყნო?** არა. GitHub issue-სა და პილოტის ფორმაში token-ები არ შეიტანოთ. BB-ის provider პარამეტრები ცალკე იმართება, Remote-ის საცდელი პანელი კი ნამდვილ გასაღებებს არ იყენებს.

**შეიძლება Remote ქმედება IDE-ში დავამტკიცო?** არა. პანელი მხოლოდ წაკითხვისთვისაა; ნებართვას ცალკე დაცული Remote გვერდი მართავს. უცნობი შედეგი წარმატებად არ ითვლება.

**რა გავაგზავნო დახმარებისთვის?** მხოლოდ OS/CPU-ის ტიპი, ვერსია და ზოგადი პრობლემა. იხ. [დახმარება](troubleshooting.ka.md) და [კონფიდენციალურობა](privacy.ka.md).

**შემიძლია პილოტში მონაწილეობა?** [საჯარო ფორმა](pilot.ka.md) ნებაყოფლობითია და ავტომატურ მოწვევას არ ნიშნავს.
