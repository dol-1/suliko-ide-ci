# პირველი ნაბიჯები (დადასტურებული ინსტალაციის შემდეგ)

1. გაუშვით BB-ის ოფიციალური Desktop პროგრამა **ლოკალურად** და გადაამოწმეთ ვერსია **0.49.0**.
2. დარწმუნდით, რომ სერვერი მხოლოდ **loopback** მისამართზე უსმენს. დაუცველი BB API საჯარო ინტერნეტში არ გამოიტანოთ.
3. გამოიყენეთ სინთეტიკური ან საჯარო საცდელი პროექტი; არ ჩაწეროთ საიდუმლო გასაღებები.
4. **Suliko Hello** პანელი ოფიციალურად დაყენებულ Windows/Linux/macOS GUI-ში მხოლოდ იზოლირებულ CI ტესტებში დადასტურდა; **Remote** ჯერ წაკითხვის რეჟიმის demo/mock-ია და არა რეალურ სერვერზე ავტორიზებული კლიენტი. ეს გზამკვლევი არც ერთ პლაგინს არ აყენებს; სრული ერთბრძანებიანი ინსტალაცია დადასტურდა **მხოლოდ იზოლირებულ 3OS CI-ში** ([D-174-ის main ტესტი](https://github.com/dol-1/suliko-ide-ci/actions/runs/43743593613)); საჯარო ინსტალატორი, RC tag, დამოუკიდებელი SEC-04 და Beta **დაუმტკიცებელია**.
5. შეცდომა აღწერეთ ზოგადად, პირადი screenshot-ისა და ანგარიშის მონაცემების გარეშე. ნახეთ [პრობლემების მოგვარება](troubleshooting.ka.md).
