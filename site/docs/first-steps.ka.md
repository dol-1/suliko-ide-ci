# პირველი ნაბიჯები (დადასტურებული ინსტალაციის შემდეგ)

1. გაუშვით BB-ის ოფიციალური Desktop პროგრამა **ლოკალურად** და გადაამოწმეთ ვერსია **0.49.0**.
2. დარწმუნდით, რომ სერვერი მხოლოდ **loopback** მისამართზე უსმენს. დაუცველი BB API საჯარო ინტერნეტში არ გამოიტანოთ.
3. გამოიყენეთ სინთეტიკური ან საჯარო საცდელი პროექტი; არ ჩაწეროთ საიდუმლო გასაღებები.
4. **Suliko Hello** და **Remote** პანელები ექსპერიმენტულია, სანამ Desktop/Web ტესტები ბოლომდე არ გაივლის.
5. შეცდომა აღწერეთ ზოგადად, პირადი screenshot-ისა და ანგარიშის მონაცემების გარეშე. ნახეთ [პრობლემების მოგვარება](troubleshooting.ka.md).

[პილოტის რეგისტრაციის ინტერესი](pilot.ka.md) ნიშნავს დაინტერესებას და არა მზად ბეტაზე წვდომას.
