# Installing — current status

**No complete Suliko one-command installer is released.** Do not use experimental scripts as a production setup.

1. Use the [official BB release page](https://github.com/get-bb/bb/releases/tag/desktop-v0.49.0) for version 0.49.0. BB supports macOS arm64 desktop, and Windows x64/Linux x86_64 desktop as **alpha** packages, with limitations described in [upstream README](https://github.com/get-bb/bb/blob/desktop-v0.49.0/README.md). Windows desktop requires Git for Windows. Intel Macs can use the upstream `npx bb-app` fallback.
2. The public [Suliko setup preflight scripts](https://github.com/dol-1/suliko-ide-ci/tree/main/scripts) are **preview-only**, when available: `suliko-setup.sh --dry-run` or PowerShell `suliko-setup.ps1 -DryRun`. Optional verified downloads check a pinned SHA-256 and **never execute or install** downloaded assets. The scripts are under active CI testing; do not interpret a passing dry-run as an installed BB.
3. A real automated hardened-profile installer and marketplace setup require additional independent checks. Until this gate passes, do not turn on a remote-access endpoint or handle real private customer data.

[First steps](first-steps.en.md) · [Troubleshooting](troubleshooting.en.md)

**Windows trust warning (BB 0.49.0):** The official pinned Windows x64 installer has been SHA-256-verified against the official release digest, but a free Windows CI runner reported Authenticode **NotSigned**. Upstream states builds without a Windows signing certificate are unsigned and may trigger SmartScreen. SHA-256 authenticates correspondence to the reviewed release digest; it does **not** establish the publisher's code-signing identity. Following Claude's narrowly reviewed the approved D-090 trust boundary, a **separate disposable user-only Windows CI smoke** permits this exact official SHA-256-pinned `NotSigned` binary without treating it as a signed publisher identity: [GH Windows run 43550483976](https://github.com/dol-1/suliko-ide-ci/actions/runs/43550483976) completed SUCCESS for NSIS `/S` per-user install, 15-second GUI liveness and owned-file uninstall. A [later disposable public Windows-2022 run 43563716016](https://github.com/dol-1/suliko-ide-ci/actions/runs/43563716016) additionally verified an **actual official installed Windows Electron `bb.exe` displaying the Suliko Hello panel**, plus a *separate but same-run pinned-stock-source CLI* with loopback SEC-02 and Hello enabled; it does not prove a complete end-user installer. [Newer official installed Windows-2025 run 43569975316](https://github.com/dol-1/suliko-ide-ci/actions/runs/43569975316) also completed SUCCESS: unchanged pinned BB source compiled with a CI-temporary VS2026-compatible toolchain; the original `NotSigned` SHA-pinned installer genuinely displayed Hello in the installed `bb.exe`, while a separate same-job source CLI verified loopback SEC-02/Hello, followed by user-scoped uninstall under 900s. **End-user Windows automated setup is still NOT approved**: official publisher signing, immutable tagged marketplace RC and integrated one-command three-OS installation remain unproven. Do not bypass SmartScreen or interpret CI success as a general installation endorsement. See the [upstream Windows packaging explanation](https://github.com/get-bb/bb/blob/desktop-v0.49.0/apps/desktop/README.md).

## Tested platform evidence, not a released installer

The following are **separate disposable GitHub-hosted CI experiments**, not instructions for installing Suliko on your own computer:

| Platform | What has been observed | Still missing |
| --- | --- | --- |

| macOS Apple Silicon | [Official SHA-pinned signed DMG installed `bb.app` Hello GUI](https://github.com/dol-1/suliko-ide-ci/actions/runs/43571275903) passed in a disposable standard macOS-15 arm64 CI home: native `codesign --verify --deep --strict` **and** `spctl --assess --type execute` Gatekeeper checks (no explicit quarantine discard), genuine Hello Electron panel, 15-second liveness, separate same-run stock CLI live loopback SEC-02/Hello, user-owned cleanup under 900s. | End-user one-command setup, immutable tagged marketplace RC and independent macOS release trust/notarization review still unproven |
| Windows x64 | Official SHA-pinned **`NotSigned`** NSIS installed non-admin on [free `windows-2025` run 43569975316](https://github.com/dol-1/suliko-ide-ci/actions/runs/43569975316), genuine installed `bb.exe` Hello GUI; same-job separate source CLI SEC-02/Hello, 15-second liveness and user-scoped uninstall under 900s. CI-only pinned native toolchain, upstream BB unchanged. | Publisher signing, immutable tagged RC marketplace, **one-command end-user setup on all three OSes** and independent security review unproven |

A CI job marked GREEN for **diagnostic inspection** must never be interpreted as an approved installation. The four beta gates, including three-platform setup and a live docs site, are not all met. Do not run unreleased Suliko scripts on production systems.

For provider configuration, use BB's official settings interface rather than posting key values anywhere. [Troubleshooting](troubleshooting.en.md) and [FAQ](faq.en.md) cover safe support requests.
